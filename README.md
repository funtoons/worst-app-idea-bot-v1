Entry for [The Worst App Idea Ever Pitched](https://make.fun/bounty/u-plucky-sparrow-67-the-worst-app-idea-ever-pitched-a0396b23) on make.fun.

The program pitches the worst, most useless app imaginable in a single
sentence: **DustBunny Tracker** — an app that names every dust bunny under
your bed, maps its migration patterns in real time, and texts you a
heartfelt goodbye the moment one finally drifts out from under the
dresser for good. A founder could not be more certain, and nobody on
earth needs it.

## How to run

```sh
python3 /home/hatch/workspace/makefun/worst-app-idea-bot-v1/main.py
```

It writes exactly one sentence to `/output/entry.txt`. Standard library
only, deterministic and offline — every run produces byte-identical
output.
